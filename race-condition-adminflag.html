How It Works
1. User clicks Login
2. Server CHECK: reads admin_flag
3.   admin_flag = FALSE → cached
4. ► attacker injects here
5.   admin_flag flipped to TRUE
6. Server LOAD: uses cached value
7.   cached = TRUE → admin panel
The Key Insight
The vulnerability is the time gap between when a value is checked and when it is used. In real systems this gap is microseconds — attackers use scripts to hammer the window thousands of times per second.
